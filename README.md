## 이번 수정 범위

- 행사·설문: 메뉴와 권한 업무에서 숨김. 기존 직접 주소는 게시물 목록으로 이동하며 원래 컨트롤러를 실행하지 않음.
- 상시 재배력: 월별 12건 구조를 제거하고 연중 한 건의 원본 교체·공개·채널 설정으로 분리. 기준 원본은 벽걸이캘린더 실제 PDF 2쪽.
- 월별 과원관리: 연도별 12개월, 준비·공개·채널 분리. 제목·본문 단·가로표의 순서와 파일을 관리. 기존 앱의 2026년 12개월 원본·1월 분할·2월 가로표를 포함.
- App 자료 미리보기: 원본 단별 확대·닫기 복귀, 가로표 좌우 이동. 월별 원본 전체 페이지 버튼은 추가하지 않음.
- 홈 연결 미리보기: 월별 자료와 재배력을 각각 해당 본문으로 연결. 자동 전환 정책은 적용하지 않음.
- 교육영상: 생육단계 분류 추가. Web·App 공개와 각 홈 선정을 독립 설정. 공동 노출 강제와 최대 3개 제한 제거. 관련자료와 App 검수 화면 추가.
- 기존 영상의 공동 메인 선정 예시는 두 채널에 같은 초기 선정값으로 나누어 보존. 이후 각 채널을 따로 변경. 새로운 선정 개수 정책을 확정한 것은 아님.
- 공지·게시글: 공지는 기존 알림 상세, 게시글은 자료 상세로 미리보기를 구분. 공개·긴급 노출과 회원 알림 발송을 분리.
- 권한: 공지·영상·상시 재배력·월별 과원관리 업무만 표시. 기관정보·행사·설문 신규 관리 제외.

## 저장과 실제 연동의 경계

재배력·월별 자료·영상 설정과 선택한 파일은 `js/resource-store.js`의 브라우저 IndexedDB에 시연 저장합니다.
같은 브라우저와 같은 HTTP 주소에서 다시 열어야 유지됩니다. 저장 실패 시 완료로 안내하지 않습니다.
다음 해 자료의 기본 등록 상태는 시연상 비공개이며 자동 공개하지 않습니다.
2026년 자료는 현재 앱의 원본으로 초기화하며, 신규 저장 자료가 있으면 같은 연도·월의 한 건을 대체합니다.
월별 원본 PDF는 보관할 수 있지만 자동으로 단·표 이미지로 분할하지 않습니다. App 본문 구성용 이미지는 별도로 선택합니다.

앱 HTML·디자인·데이터 원본은 수정하지 않았습니다. 관리자 저장이 실제 앱에 자동 반영되는 상태는 아닙니다.
API·회원정보·납부·문서 시스템·푸시 발송·외부 영상 수집은 연동 전입니다. 수집 버튼은 가짜 완료 건수를 표시하지 않습니다.
공지와 기존 알림의 실제 데이터 연결, 개인 알림 공개 범위, 긴급 우선순위·홈 슬라이드 자동 전환·월별 공개 시점·홈 영상 개수/대체·알림 운영 위치는 미정입니다.
새로 추가한 파일 입력의 허용 형식은 검수용입니다. 운영 파일 제한은 개발 협의가 필요합니다.
`docs/survey-*` 문서는 추후 검토용 보존 자료이며 이번 개발 범위가 아닙니다.

## 콘텐츠 시연 데이터

콘텐츠 목록은 브라우저의 `localStorage`를 시연 저장소로 사용합니다. 저장 키는 `peach-admin-demo-contents`입니다.

처음 목록을 열면 `js/mock-data.js`의 50건이 이 키에 저장됩니다. 이후 등록, 임시저장, 수정, 삭제 결과는 이 키에만 남으며, 새로고침 후에도 유지됩니다. 이 저장 방식은 화면 시연용이며 실제 서비스의 저장 방식이 아닙니다.

각 콘텐츠는 등록일 `registeredAt`과 수정일 `updatedAt`을 따로 가집니다. 날짜가 하나뿐인 기존 데이터는 그 날짜를 두 값에 같이 사용합니다. 목록의 수정·등록일 열은 수정일을 표시합니다. 한 번도 수정하지 않은 항목은 두 날짜가 같아 기존 화면과 같은 날짜가 보입니다.

긴급공지 활성 여부는 저장하지 않습니다. 목록을 그릴 때 공개 여부, 게시기간, 긴급기간과 현재 날짜로 계산합니다.

대표 이미지와 첨부파일은 서버에 업로드하지 않습니다. 파일 이름, 형식, 크기만 저장하고, 200KB 이하 대표 이미지만 미리보기용 데이터로 함께 보관합니다. 그 크기를 넘는 이미지와 첨부파일 원본은 새로고침 후 다시 열 수 없습니다.

## 초기 데이터로 되돌리기

사용자 화면에는 초기화 버튼이 없습니다. 아래 중 하나로 시연 데이터를 지운 뒤 콘텐츠 목록을 새로고침하면 처음 50건이 다시 저장됩니다.

1. 브라우저 개발자 도구의 콘솔에서 실행합니다.

```js
localStorage.removeItem("peach-admin-demo-contents")
```

2. 개발자 도구의 Application 또는 저장소 메뉴에서 `peach-admin-demo-contents` 항목을 삭제합니다.
