## 확정 기준
- 설문은 회원 확인·대상·채널 설정 없이 링크로 참여합니다. 설문 본인 참여내역은 없습니다.
- 행사·교육은 이름·휴대폰 번호를 기존 복숭아자조금 회원과 매칭한 뒤 신청·본인 내역을 조회합니다. 별도 SMS·가입 단계를 추가하지 않습니다.
- 정원은 참석 확정만 집계합니다. 대기 미사용은 정원 도달 시 미참석 포함 전체 접수를 마감합니다. 대기 사용은 초과 참석을 대기로 접수합니다.
- 대기 자동 승격·신청 취소·승인·자동 알림은 범위에 없습니다. 대기는 확정과 구분해 확인합니다.
- 종료일 미지정은 시작일로부터 달력상 1년 뒤 자동 종료입니다.
- 미리보기 제출은 결과·본인 내역·정원·대기·질문 잠금에 반영하지 않습니다.
- 저장은 설문 공개와 링크 생성을 포함하고, 임시저장은 미공개입니다.

## 현재 퍼블과 운영 연결의 구분
- 퍼블의 설문·행사 목록·문서·응답·동의 기본문구는 브라우저 저장으로 동작합니다. 서로 다른 기기·브라우저·포트에서 공유되지 않습니다.
- 외부 링크 실운영에는 문서 조회·응답 저장·회원 매칭·본인 내역·정원 동시 접수 처리를 운영 시스템에 연결해야 합니다.
- 관리자 공통 가입코드·이름은 퍼블에서 브라우저 저장으로 확인합니다. 운영에서는 관리자 전체에 공통인 코드 한 개를 사용하고 재발행 시 이전 코드를 즉시 무효화합니다.
- 관리자 가입·SMS 인증·비밀번호·휴대폰 변경은 연동 지점과 실패 안내를 제공합니다. 연결 전 성공으로 처리하지 않습니다.
- 행사 회원 확인 오류는 팝업에서 입력을 유지합니다. 관리자 SMS 휴대폰 인증과 행사 회원 확인은 별개입니다.
- 사용자 화면에는 구현 상태 설명을 넣지 않습니다. 실제 연결 필요 범위는 이 문서와 검수 결과에서 확인합니다.

## 참여 중 이동과 오류
- 질문 이전·다음은 실제 방문 경로를 따릅니다. 상단 메뉴·상세로·브라우저 뒤로/앞으로 이동 시 작성 답변이 있으면 이탈 확인을 거칩니다.
- 계속 작성·닫기는 현재 질문과 답변을 유지합니다. 나가기는 입력을 버리고 선택한 화면으로 이동합니다. 새로고침·탭 닫기는 브라우저 기본 이탈 확인을 사용합니다.
- 문서·동의 변경 오류는 입력 화면에서 이유와 상세로 돌아가기를 표시합니다. 변경된 문서를 확인한 뒤 다시 작성합니다. 일시적인 제출 실패는 같은 요청으로 재시도합니다.
