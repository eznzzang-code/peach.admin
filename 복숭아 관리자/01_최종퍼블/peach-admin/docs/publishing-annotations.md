# 퍼블리싱 안내 문구 구분

녹색이라는 색만으로 최종 화면 문구 여부를 판단하지 않습니다.
- flow-guide 등에는 공지 저장과 알림 발송 구분, 별도 연동·검수 주소 등 작업 확인용 설명이 섞여 있습니다. 기존 게시글·재배력·영상 문구 전체가 이번 화면기획서 범위에 수록된 것은 아닙니다.
- 저장 완료·인증 완료 등 실제 처리 상태와 입력 조건 안내는 이용자에게 필요한 화면 문구입니다.
- 최신 화면기획서는 화면 구성·입력 조건·이동 흐름만 기록합니다. 개발팀 전달용 API·저장소·작업 이력·검수 주석을 제거했습니다. 구현 연결 계약은 이 docs 폴더에서 별도로 확인합니다.

이번 변경은 기획서의 전달용 문구 정리입니다. 기존 다른 메뉴의 녹색 안내를 일괄 삭제하거나 실제 성공/오류 안내를 삭제하지 않았습니다.
