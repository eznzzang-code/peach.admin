# 설문·행사교육 최종 퍼블리싱 통합 · 2026.10.28

기준: 화면기획서 v8 검수반영(56장). 운영 서버 구현 전의 정적 퍼블리싱입니다.

최신 문서 우선순위와 연결 필요 기능은 README.md를 먼저 확인합니다. archive/previous-survey는 현재 기준이 아닙니다.

## 변경 범위

- 설문·행사 메뉴를 js/common.js에서 기존 사이드바에 추가합니다. 원래 링크가 있으면 중복 생성하지 않습니다. 다른 메뉴의 마크업·활성화·펼침·클릭 처리와 로그인은 유지합니다.
- surveys-*.html / events-*.html은 기존 관리자 헤더와 사이드바를 사용합니다. 숨김 body와 게시글 리다이렉트, 기존 보류 안내와 연결되지 않은 이전 컨트롤러 참조를 제거했습니다.
- 새 업무 모듈은 js/participation, css/participation에 분리했습니다. 다른 메뉴 HTML은 수정하지 않았습니다. 기존 공통 CSS·업무 데이터·다른 컨트롤러는 유지합니다.
- participant.html은 생성 링크의 공통 상세/질문/동의/완료/본인내역입니다. 설문은 인증 없이, 행사·교육은 회원 확인 후 신청합니다. 행사 인증은 이름·휴대폰 번호를 입력하는 회원 확인 팝업이며, 복숭아자조금 회원 조회와 연결합니다.

## 적용 기능

1. 제목·기간·상태 조회, 겹치는 기간 양끝 포함, 작성중 문서 삭제, 공개 설문 목록/상세 문항 미리보기.
2. 질문 카드·유형(단일/복수/단답/장문/평점)·필수·설명·선택지·복사/추가/삭제/순서·답변별 이동·화살표 흐름도. 화면에 분기 용어를 사용하지 않습니다.
3. 설문 저장은 필수 검증 후 공개 등록과 링크 생성입니다. 임시저장은 미공개입니다. 참여방식은 설문 작성/기본정보에 표시하지 않습니다.
4. 종료일 미지정은 시작일로부터 달력상 1년 뒤 자동 종료입니다. 수동 종료일도 최대 1년입니다. 새 문서는 현재 작성 시각, 기존 날짜는 보존합니다.
5. 개인정보 동의는 기본 포함, 포함 여부 선택 및 목적·항목·보유기간 수정/다음 새 문서 기억. 참여 시 마지막 질문과 별도 화면, 모든 질문 이동 경로의 제출 전 공통 조건. 완료 안내는 작성 화면 맨 아래.
6. 행사 하루/기간 개최 일정과 신청기간을 구분. 고정 참석/미참석 필수 문항 아래에 사용자 질문 추가.
7. 정원 미적용은 무제한. 적용/대기 미사용은 정원 도달 시 미참석 포함 전체 접수 마감. 대기 사용은 초과 참석을 대기로 접수. 미참석·대기는 확정 정원 제외. 자동 승격/취소/승인/발송은 추가하지 않습니다.
8. 미리보기 전체 문항 수는 questions.length(동의 제외). 입력/제출은 운영 결과·정원·내역·잠금에 쓰지 않습니다.
9. 응답 이후 구조 잠금, 행사 주요 일정/장소 변경 확인, 응답 있는 문서 삭제 차단, 숨김/기간/정원/인증/중복/동의 검증, CSV, 문서 복사·비공개·종료.
10. 회원별 행사·교육 참여내역, 관리자 전체 문항과 건너뜀 표시/행사 본인 상세는 실제 방문 문항만 표시. 설문은 참여내역에서 제외합니다. 평점 형식과 문서 revision 검증.

## 저장/API 교체

저장 키는 peach-admin-participation:v1 입니다. 없으면 기존 peach-survey-prototype:v1를 읽어 다음 저장 시 새 키에 보관하며 기존 키는 삭제하지 않습니다. forms/consentDefaults 버전4이며 첫 시작은 빈 목록입니다. 기존 MockData의 집계용 가상 응답 수를 실제 응답으로 생성하지 않습니다. 저장소는 브라우저와 origin(포트 포함) 범위입니다.

서버 연결 지점은 js/participation/store.js 입니다. 운영 배포 시 목록/폼/기본 문구/제출 API와 실제 인증으로 교체합니다. 서버에서 권한·Asia/Seoul 기준 기간·formRevision·동의 문구·본인 조회·submissionId 고유 제약·행사 중복·정원을 한 트랜잭션으로 검사해야 합니다. 현재 로컬 저장은 다중 탭 동시성이나 외부 기기 링크 접속을 보장하지 않습니다. 알림 대상 선택·발송·발송 결과는 통합자조금 시스템에서 관리합니다.

## 검증 실행

Node.js로 tests/participation의 model.test.cjs, operation.test.cjs, event.test.cjs, integration.test.cjs를 실행합니다. 테스트는 메모리 저장소를 사용하며 실제 브라우저 데이터를 바꾸지 않습니다. 실제 로그인은 기존 demo-auth.js의 테스트 계정 체계를 유지합니다.


## 직접 파일 열기 호환 수정

HTML을 file://로 직접 열 때 다른 파일 경로로 history.replaceState를 시도하면 SecurityError로 작성 화면 렌더링이 중단될 수 있었습니다. 관리자 화면은 같은 실제 파일의 #screen=... 해시로 상태를 기록하고 그 해시에서 문서·화면을 복원합니다. HTTP에서는 기존 업무별 URL을 유지합니다. URL 갱신이 거부되어도 화면 생성 자체는 계속합니다. 참여 페이지도 파일 직접 열기에서는 해시로 화면 상태를 기록합니다.

저장·참여 링크·본인 내역의 공통 저장 공간은 HTTP 방식으로 확인하세요. 미리보기_실행.cmd를 실행하면 이 최종 폴더를 http://127.0.0.1:8798/로 제공합니다. 브라우저의 file:// 저장소 범위는 브라우저별로 다를 수 있으므로 파일과 HTTP 간 데이터를 자동으로 복사하거나 삭제하지 않습니다. 운영 API 연결 범위는 변경하지 않았습니다.


## 참여내역 정책 변경 · 2026.10.28

참여내역은 회원 ID로 식별하는 행사·교육 신청에 한정합니다. 참석 확정·미참석·대기를 모두 포함하며 인증한 회원 본인의 내역만 표시합니다. 비로그인 상태에서는 회원 확인 안내를 표시합니다. 설문/행사 구분 탭은 제거합니다.

설문은 비회원 참여이며 본인 참여내역 목록/상세를 제공하지 않습니다. 설문 완료 버튼은 설문 목록으로 이동합니다. 기존 설문 mine URL이나 kind=survey로 참여내역을 요청해도 설문 답변을 노출하지 않고 행사·교육 참여내역으로 처리합니다. 설문 응답 자체와 관리자 결과·CSV·미리보기 무저장 정책은 유지하며 기존 저장 응답을 삭제하지 않습니다. 내부 방문자 식별값은 제출 재시도 처리 등에 사용될 수 있으나 설문 내역 조회 권한으로 사용하지 않습니다.

행사·교육의 회원 확인·중복 신청 방지·정원·대기·완료·본인 상세는 유지합니다. 운영 API에서도 행사 memberId와 현재 인증 회원을 대조해야 합니다. 행사 회원 확인 결과는 별도 이력으로 저장하지 않습니다. 기존 테스트 회원 자동 통과는 제거했습니다.


## 최종 퍼블·기획 대조 수정 · 2026.10.28

회원 화면의 정원·확정 인원·잔여 인원과 진행 막대는 표시하지 않습니다. 관리자 기본정보/신청자 관리의 정원 및 확정·미참석·대기 집계는 유지합니다. 회원에게는 대기 접수 가능성, 현재 대기 접수/마감과 본인의 접수 상태만 안내합니다. 정원 판정과 대기 처리는 그대로입니다.

설문/행사 관리자 목록은 제목 클릭 시 공개 문서는 운영 상세, 작성중 문서는 작성으로 이동합니다. 별도 상세/이어서 작성 버튼은 제거하고 문항 미리보기와 삭제는 유지합니다. 참여 목록은 제목 클릭으로 문서 상세, 회원 행사 참여내역은 제목 클릭으로 본인 신청 상세를 엽니다.

미리보기에서도 포함된 동의의 세 문구를 검증합니다. 행사 참석 문항은 정원 적용·대기 접수 사용 시 대기 가능성을 안내합니다. 관리자 신청자는 회원 ID와 이름을 함께 표시합니다. 관리자 답변은 전체 문항/건너뜀/동의, 회원 본인 답변은 실제 방문 문항을 표시합니다. 비회원 설문은 본인 내역을 제공하지 않습니다.

회귀 검증에 alignment.test.cjs를 추가했습니다. 실제 서버의 회원 확인·조회 권한·정원 동시성·기기 간 공유는 기존 API 통합 범위입니다.


## 행사·교육 문항 미리보기 및 회원 확인 변경
공개된 행사·교육 목록의 관리 열과 상세 상단에 문항 미리보기를 제공합니다. 상세의 신청자 관리 탭에도 동일 상단 버튼이 유지됩니다. 작성중 문서는 기존 작성 화면 미리보기를 사용합니다. 참석 여부·추가 문항·별도 동의·완료까지 체험하며 결과/정원/대기/내역/문서 버전을 저장하지 않습니다.

행사 상세의 회원 확인 후 계속은 이름·휴대폰 번호 팝업을 엽니다. 기존 복숭아자조금 회원과 매칭 성공하면 신청 문항으로 바로 이동합니다. 별도 회원가입·SMS 단계를 추가하지 않습니다. 불일치는 입력 팝업에 안내하고 취소는 기존 상세로 복귀합니다. 내 참여내역을 확인할 때도 같은 회원 확인을 사용합니다. 인증 결과는 메모리에서 현재 흐름에만 사용하며 별도 이력이나 브라우저 저장소에 보관하지 않습니다. 실제 행사 신청 결과는 기존과 같이 보관합니다. 실제 회원 조회 연결 계약은 event-member-matching.md에 기록했습니다.
