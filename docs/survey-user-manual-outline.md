# 설문 관리 사용자 매뉴얼 초안

관리자 화면 기준입니다. 지금 저장소는 화면 검수용 예시 데이터로 동작하며, 서버 저장은 연결되어 있지 않습니다. 아래 **현재 불가**로 표시한 기능은 안내 창까지만 진행되고 실제로는 반영되지 않습니다. 이 표시는 **서버 연동 필요**입니다. 화면에서 입력 검증과 조회가 되는 부분은 **구현 완료**, 아직 확정되지 않은 대상 코드와 응답 정책은 **개발 협의 필요**, Mock Data와 테스트 데이터 미리보기는 **테스트 전용**입니다.

캡처는 아직 넣지 않았습니다. 각 절의 “캡처 위치”에 촬영할 화면만 적었습니다.

## 1. 설문 관리 화면 이해하기

설문 관리는 왼쪽 메뉴 **설문 관리**에서 엽니다.

| 화면 | 하는 일 |
| --- | --- |
| 설문 목록 | 등록된 설문을 찾고 상세나 응답 결과로 이동 |
| 신규등록 | 새 설문 내용을 작성 |
| 임시저장 | 아직 등록하지 않은 초안 목록을 확인 |
| 설문 상세 | 등록된 내용을 읽기 전용으로 확인 |
| 설문 수정 | 진행 전·진행 중 설문 수정을 요청 |
| 응답 결과 | 진행 중·종료 설문의 문항별 결과를 확인 |

설문 상태는 세 가지입니다.

- **진행예정:** 시작일시가 아직 오지 않음
- **진행중:** 시작일시가 지났고, 종료되지 않음
- **종료:** 종료일시가 됐거나, 관리자가 종료한 설문

종료일 없음은 종료일시를 정하지 않은 설문입니다. 자동으로 끝나지 않고, 진행중일 때 관리자가 종료할 수 있습니다.

**주의:** 상태 계산은 관리자 PC의 현재 시각을 사용합니다. 목록은 상태 탭, 검색, 초기화를 할 때 다시 계산합니다. 페이지를 열어 둔 채 시간이 지나도 목록·상세·수정 화면이 저절로 바뀌지는 않습니다. 수정 완료와 설문 종료 확인은 누르는 시점의 상태를 다시 확인합니다. 서버 기준 시각은 연동 후 다시 확인이 필요합니다.

**캡처 위치:** 사이드바에서 설문 관리가 선택된 목록 상단.

## 2. 설문 목록 검색하기

### 기능

상태, 기간, 설문명, 소개로 목록을 좁힙니다. 한 페이지에 10건씩 보이며, 최근에 등록된 설문이 위에 옵니다.

### 사용 순서

1. 전체, 진행중, 진행예정, 종료 탭 중 하나를 누릅니다. 상태 드롭다운도 같은 값으로 바뀝니다.
2. 기간이 필요하면 전체기간, 최근 1·3·6개월, 직접 기간 중 선택합니다. 기간은 설문 **시작일** 기준입니다.
3. 검색 대상을 제목+내용, 제목, 내용 중에서 고릅니다. 내용은 설문 소개입니다.
4. 검색어를 입력하고 **검색**을 누르거나 검색어 칸에서 Enter를 누릅니다.
5. 조건을 지우려면 **초기화**를 누릅니다.

### 주의

- 기간과 검색어는 검색을 눌러야 적용됩니다. 상태 탭은 누르는 즉시 적용됩니다.
- 직접 기간은 시작일과 종료일을 모두 골라야 합니다.
- 진행예정 설문의 응답수는 `-`로 보입니다.
- 긴 설문명은 칸 안에서 말줄임으로 보입니다. 마우스 올리면 전체 제목이 나오고, 이름을 누르면 상세에서 전체를 볼 수 있습니다.
- 진행중·종료만 **응답보기**가 연결됩니다.

**캡처 위치:** 검색 조건 한 줄과 표 헤더. 진행예정의 응답수 `-`와 비활성 응답보기가 같이 보이게.

## 3. 새 설문 등록하기

### 기능

시작·종료, 설문명, 소개, 참여 대상, 문항을 입력한 뒤 등록을 요청합니다.

### 사용 순서

1. 목록에서 **+ 신규등록**을 누릅니다.
2. 시작일과 시작시간을 선택합니다. 시작시간은 기본 09:00입니다.
3. 종료일과 종료시간을 선택합니다. 종료시간은 기본 18:00입니다. 종료일을 정하지 않으려면 **종료일 없음**을 켭니다.
4. 설문명과 소개를 입력합니다.
5. **대상 선택**과 **문항 편집**을 마칩니다.
6. **미리보기**로 내용을 확인합니다.
7. **등록**을 누릅니다.

### 주의

- 시작일시는 현재 시각보다 이전일 수 없습니다.
- 종료일시는 현재보다 뒤이고, 시작일시보다 뒤여야 합니다.
- 설문명, 소개, 대상, 문항 1개 이상은 필수입니다.
- 문항은 제목이 있어야 합니다. 단일·복수 선택은 내용이 있는 선택지 2개 이상 10개 이하여야 합니다. 내용이 잘못되면 그 이유가 표시되고, 등록 안내로 넘어가지 않습니다.
- 입력을 마치고 목록으로 나가면 “입력한 내용을 저장하지 않고 이동하시겠습니까?”라고 묻습니다.

**현재 불가:** 등록을 눌러 검증을 통과해도 “서버가 연결되지 않아 설문을 등록할 수 없습니다.”만 나타납니다. 목록에 새 설문이 생기지 않습니다.

**캡처 위치:** 신규등록 폼 전체와, 검증 오류가 필드 아래에 나온 상태. 등록 안내 창은 따로.

## 4. 설문 문항 작성하기

### 기능

단일 선택, 복수 선택, 주관식 문항을 만들고 순서를 바꿉니다.

### 사용 순서

1. **문항 편집**을 엽니다.
2. **문항 추가**를 누릅니다. 새 문항은 단일 선택, 필수응답, 빈 선택지 2개입니다.
3. 질문을 입력합니다. 설명은 필요할 때만 입력합니다.
4. 유형을 고릅니다.
5. 객관식은 선택지 문구를 입력합니다. 2개 미만이거나 10개를 넘길 수 없습니다.
6. 필요하면 복제, 삭제, 끌어서 순서를 바꿉니다.
7. **적용**을 누릅니다. 적용 전에는 설문 본문에 반영되지 않습니다.

### 주의

- 객관식을 주관식으로 바꾸면 선택지가 삭제됩니다. 확인 창이 먼저 열립니다.
- 주관식을 객관식으로 바꾸면 빈 선택지 2개가 생깁니다. 단일 선택과 복수 선택 사이에는 선택지 문구가 유지됩니다.
- 필수응답을 끄면 상세와 미리보기에 선택응답으로 표시됩니다. 응답자가 반드시 답하게 하는 기능은 아직 없습니다.
- 주관식의 “최대 1,000자”는 안내 문구입니다. 응답 화면은 아직 없습니다.
- 편집 중 닫으면 변경을 버릴지 묻습니다.

**캡처 위치:** 문항 편집 모달에서 선택지와 오류 문구. 유형 변경 확인 창.

## 5. 설문 대상 선택하기

### 기능

전체 회원 또는 조건별 대상을 고릅니다.

### 사용 순서

1. **대상 선택**을 엽니다.
2. **전체 회원** 또는 **조건별 대상**을 고릅니다.
3. 조건별 대상이면 지역, 회원 구분 중 필요한 항목을 고릅니다.
4. **적용**을 누릅니다.

### 주의

- 지역이나 회원 구분을 여러 개 고르면 그중 하나에 해당하면 포함되는 조건입니다.
- 지역과 회원 구분을 함께 고르면 둘 다 만족해야 하는 조건입니다.
- 화면에 보이는 지역·회원 구분 이름은 검수용 예시입니다. 실제 회원 구분 값은 아직 확정되지 않았습니다.
- 작성 중 선택한 조건과 목록에 보이는 대상 문구는 역할이 다릅니다. 조건 자체가 원본이고, 화면에 보이는 문장은 그 조건을 읽기 쉽게 만든 표시입니다.
- 누가 설문에 참여할 수 있는지는 이 화면에서 계산하지 않습니다.
- 적용 전에 닫으면 선택 내용을 버릴지 묻습니다.

**캡처 위치:** 참여 대상 선택 모달의 안내 문장과 체크 영역.

## 6. 설문 미리보기

### 기능

응답자에게 보일 내용을 읽기 전용으로 확인합니다. 등록, 수정, 상세, 문항 편집에서 열 수 있습니다.

### 사용 순서

1. **미리보기**를 누릅니다.
2. 제목, 소개, 기간, 대상, 문항과 선택지를 확인합니다.
3. **닫기** 또는 Esc로 닫습니다.

### 주의

- “읽기 전용입니다. 응답은 저장되지 않습니다.”
- 비어 있는 항목은 미입력으로 표시됩니다.
- 미리보기에서 선택한 답은 저장되지 않습니다.

**캡처 위치:** 미리보기 창 상단 안내와 문항 하나.

## 7. 임시저장 설문 관리하기

### 기능

등록된 설문과 따로 보관된 초안 목록입니다. 제목이 없으면 `(제목 없음)`으로 보입니다. 마지막 수정일이 최근인 항목이 위에 옵니다.

작성 상태는 자동으로 계산됩니다.

- **등록 가능:** 설문명, 소개, 기간, 대상, 문항이 등록 조건을 만족
- **입력 필요:** 아직 빠진 항목이 있음

### 사용 순서

1. 목록의 **임시저장** 건수를 누릅니다.
2. 이어 작성 또는 삭제를 누릅니다.
3. 목록으로 돌아가려면 **목록으로**를 누릅니다.

### 주의

**현재 불가**

- 신규등록의 **임시저장**은 “서버가 연결되지 않아 임시저장할 수 없습니다.” 목록 건수가 늘지 않습니다.
- **이어 작성**은 “서버가 연결되지 않아 이어 작성할 수 없습니다.” 작성 화면으로 내용이 넘어가지 않습니다.
- **삭제**는 확인 후 “서버가 연결되지 않아 삭제할 수 없습니다.” 목록에서 사라지지 않습니다.

**캡처 위치:** 임시저장 표의 제목 없음, 작성 상태, 이어 작성·삭제 버튼.

## 8. 등록된 설문 확인하기

### 기능

목록에서 설문명을 누르면 상세가 열립니다. 기간, 대상, 응답 수를 읽기 전용으로 봅니다. 문항은 **문항보기**를 눌러 팝업에서 확인합니다. 단일·복수 선택 항목에는 `1.` `2.` 번호가 붙습니다.

### 사용 순서

1. 목록에서 설문명을 누릅니다.
2. 상태를 확인하고, 문항은 **문항보기**에서 확인합니다.
3. 필요하면 미리보기, 수정, 종료, 삭제를 사용합니다.
4. **목록**으로 돌아갑니다.

### 주의

- 종료일 없음은 “종료일 없음”으로 표시되고 종료일시 칸은 숨겨집니다.
- 긴 설문명은 상세 입력칸과 마우스 도움말로 전체를 확인할 수 있습니다.
- 진행예정은 수정만 가능하고 설문종료는 없습니다.
- 진행중은 수정과 설문종료가 있습니다.
- 종료는 수정과 설문종료가 없습니다.
- 응답이 있으면 삭제가 비활성입니다. “응답이 있는 설문은 삭제할 수 없습니다.”

**캡처 위치:** 진행중 상세의 상태, 종료일, 문항보기 버튼, 문항 팝업, 하단 버튼. 종료일 없음 설문은 별도 캡처.

## 9. 설문 수정하기

### 기능

진행 전 설문은 내용 전체를, 진행 중 설문은 일부만 수정할 수 있습니다.

### 사용 순서

1. 상세에서 **수정**을 누릅니다.
2. 허용된 항목만 바꿉니다.
3. 필요하면 미리보기로 확인합니다.
4. **수정 완료**를 누릅니다.

### 주의

| 상태 | 수정할 수 있는 항목 |
| --- | --- |
| 진행예정 | 시작·종료, 설문명, 소개, 대상, 문항 |
| 진행중 | 설문명, 소개, 종료일시 또는 종료일 없음. 시작일시·대상·문항은 잠김 |
| 종료 | 수정 화면이 열리지 않음. “종료된 설문은 수정할 수 없습니다.” |

진행중에도 종료일시는 현재보다 뒤이고 시작일시보다 뒤여야 합니다. 수정 완료를 누르는 시점의 상태를 다시 확인합니다. 그 사이 설문이 종료되면 수정할 수 없다는 안내만 나오고 저장되지 않습니다.

수정 중 다른 화면으로 나가면 “수정 중인 내용을 저장하지 않고 이동하시겠습니까?”라고 묻습니다.

**현재 불가:** 수정 완료를 눌러도 “서버가 연결되지 않아 수정 내용을 저장할 수 없습니다.”만 나타납니다. 원래 설문은 바뀌지 않습니다.

**캡처 위치:** 진행중 수정 화면에서 잠긴 시작일과 대상. 종료 설정의 차단 문구는 별도.

## 10. 설문 종료하기

### 기능

진행중인 설문을 관리자가 끝냅니다. 종료일 없음 설문도 진행중이면 종료할 수 있습니다.

### 사용 순서

1. 진행중 상세에서 **설문종료**를 누릅니다.
2. “진행 중인 설문을 종료하시겠습니까?”를 확인합니다.
3. 안내를 읽습니다. “종료된 설문은 다시 진행할 수 없으며, 설문 내용을 수정할 수 없습니다.”
4. **설문 종료** 또는 **취소**를 누릅니다.

### 주의

- 진행예정과 종료 설문에는 이 버튼이 없습니다.
- 취소, 닫기, Esc는 설문을 바꾸지 않습니다.

**현재 불가:** 확인을 눌러도 “서버가 연결되지 않아 설문을 종료할 수 없습니다.”만 나타납니다. 상태는 진행중 그대로입니다.

**캡처 위치:** 설문 종료 확인 창.

## 11. 설문 삭제하기

### 기능

응답이 없는 설문만 삭제할 수 있습니다.

### 사용 순서

1. 상세에서는 **삭제**를 누릅니다. 목록에서는 해당 행을 선택한 뒤 **삭제**를 누릅니다.
2. “이 설문을 삭제하시겠습니까?”와 “삭제한 설문은 복구할 수 없습니다.”를 확인합니다.
3. **삭제** 또는 **취소**를 누릅니다.

### 주의

- 응답이 1건이라도 있으면 삭제할 수 없습니다.
- 목록에서 여러 개를 고르면, 그중 하나라도 응답이 있으면 삭제 버튼이 꺼집니다.
- 진행예정, 진행중, 종료 모두 응답이 0건이면 삭제 버튼은 켜집니다. 실제 삭제는 아직 되지 않습니다.

**현재 불가:** 확인 후 “서버가 연결되지 않아 설문을 삭제할 수 없습니다.” 설문은 목록에 남습니다.

**캡처 위치:** 응답 있는 설문의 비활성 삭제와 안내. 삭제 확인 창은 별도.

## 12. 설문 응답 결과 확인하기

### 기능

진행중·종료 설문의 문항별 결과를 봅니다. 진행예정은 열 수 없습니다. “진행예정 설문은 응답 결과를 조회할 수 없습니다.”

### 사용 순서

1. 목록에서 **응답보기**를 누릅니다.
2. 왼쪽에서 문항을 선택합니다.
3. 단일·복수 선택은 선택지별 응답 수와 비율을, 주관식은 최신 답변을 10건씩 확인합니다.
4. 기간이 필요하면 전체, 최근 1·3·6개월, 직접 선택을 고르고 **검색**을 누릅니다.
5. 파일이 필요하면 **Excel 다운로드**를 누릅니다.

### 주의

- 상단 **전체 유효 응답 수**는 설문 전체 응답 수입니다.
- 문항 안 **유효 응답 수**는 그 문항의 응답 수입니다. 둘은 다를 수 있습니다.
- 현재 예시 데이터에는 문항별 응답이 연결되어 있지 않습니다. “문항별 응답 데이터가 연결되지 않았습니다.”와 `—`가 정상입니다.
- 복수 선택은 한 사람이 여러 개를 고를 수 있어 비율 합이 100%를 넘을 수 있습니다.
- 주관식의 긴 답변은 칸 안에서 줄바꿈됩니다.

**현재 불가**

- 기간 검색은 날짜를 검사한 뒤 “서버가 연결되지 않아 선택한 기간의 응답 결과를 조회할 수 없습니다.” 화면에 보이는 응답 수는 바뀌지 않습니다.
- Excel은 “서버가 연결되지 않아 Excel 파일을 다운로드할 수 없습니다.” 파일이 내려받아지지 않습니다.

**테스트 데이터 미리보기**는 개발·검수용입니다. 기본은 꺼져 있습니다. 지원하는 검사용 설문에서만 켤 수 있고, “테스트 데이터입니다. 실제 설문 응답이 아닙니다.”가 표시됩니다. 이때 문항 숫자는 “테스트 유효 응답 수”이며 상단의 전체 응답 수와 다릅니다. 운영 응답으로 사용하지 않습니다. 다른 설문은 “이 설문은 테스트 데이터 미리보기를 지원하지 않습니다.”

**캡처 위치:** 데이터 미연결 상태의 결과 화면. 테스트 미리보기를 켠 객관식과 주관식 3페이지는 검수용으로 따로 표시.

## 13. 자주 발생하는 오류와 해결 방법

| 증상 | 확인 |
| --- | --- |
| 시작일시는 현재 또는 미래만 선택할 수 있습니다. | 시작일시를 지금 이후로 바꿉니다. 진행중 수정에서는 시작일시를 바꾸지 않습니다. |
| 종료일시는 현재보다 이후여야 합니다. | 종료일시를 현재보다 뒤로 바꿉니다. |
| 종료일시는 시작일시보다 늦어야 합니다. | 종료를 시작보다 뒤로 바꿉니다. |
| 설문명을 입력해 주세요. / 설문 소개를 입력해 주세요. | 공백만 있는지도 확인합니다. |
| 참여 대상을 선택해 주세요. | 대상 선택에서 전체 회원 또는 조건을 적용합니다. |
| 지역 또는 회원 구분을 1개 이상 선택해 주세요. | 조건별 대상이면 지역이나 회원 구분을 하나 이상 고릅니다. |
| 문항을 1개 이상 등록해 주세요. | 문항 편집에서 문항을 만들고 **적용**을 누릅니다. |
| 문항 제목을 입력해 주세요. / 선택지 문구를 입력해 주세요. | 문항 편집에서 빈칸을 채운 뒤 적용합니다. 등록·수정 완료 때도 같은 문구로 막힙니다. |
| 선택지는 2개 이상, 10개까지 | 객관식 선택지 개수를 맞춥니다. |
| 지원하지 않는 문항 유형입니다. | 단일 선택, 복수 선택, 주관식만 사용할 수 있습니다. |
| 시작일과 종료일을 모두 선택해 주세요. | 목록과 응답 결과의 직접 기간이 같은 문구입니다. 목록은 설문 시작일, 응답 결과는 응답 제출일 기준입니다. |
| 시작일은 종료일보다 늦을 수 없습니다. | 기간의 시작일과 종료일 순서를 바꿉니다. |
| 응답이 있는 설문은 삭제할 수 없습니다. | 응답이 있으면 삭제할 수 없습니다. |
| 종료된 설문은 수정할 수 없습니다. | 종료 후에는 수정 화면으로 들어갈 수 없습니다. |
| 진행예정 설문은 응답 결과를 조회할 수 없습니다. | 시작 후에 응답보기를 사용합니다. |
| 서버가 연결되지 않아 … | 등록, 수정, 임시저장, 삭제, 종료, 기간 조회, Excel은 아직 실행되지 않습니다. 안내를 닫아도 데이터는 그대로입니다. |
| 문항별 응답 데이터가 연결되지 않았습니다. | 문항별 통계가 아직 연결되지 않은 상태입니다. 상단 전체 응답 수와는 별개입니다. |

**캡처 위치:** 필드 아래 오류 한 가지와, 서버 미연결 안내 창.
