# 설문 관리 기능 정의서

작성 기준: STEP 3~13-2 관리자 화면 코드. 이 문서는 현재 프런트엔드 동작을 정리한 자료입니다. 서버 API는 연결되어 있지 않습니다. `js/mock-data.js`의 설문 목록은 화면 검수용 예시이며 운영 데이터가 아닙니다.

구분 표시:

- **구현 완료:** 화면에서 동작이 확인되는 기능. 본문 표의 **구현**
- **서버 연동 필요:** 버튼과 안내는 있으나 저장·조회·다운로드는 하지 않음. 본문 표의 **미연결**
- **개발 협의 필요:** 코드만으로 정책을 확정할 수 없음. 본문 표의 **확인 필요**
- **테스트 전용:** Mock Data와 응답 결과 테스트 미리보기. 운영 데이터가 아님
- **미구현:** 관리자 코드에 해당 기능이 없음. 구현 완료가 아님

### 동작

- **구현:** `MockData.surveys`를 `registeredAt` 내림차순, 같으면 `id` 내림차순으로 정렬
- **구현:** No는 현재 필터 결과에서 최신이 큰 번호
- **구현:** 탭과 상태 드롭다운은 서로 맞추고, 바꾸면 1페이지
- **구현:** 검색은 검색 버튼 또는 검색어 칸 Enter. 드롭다운만 바꿔도 검색 전에는 목록에 반영되지 않음. 상태 탭·드롭다운은 바로 반영
- **구현:** 키워드는 앞뒤 공백을 제거하고 대소문자를 구분하지 않음. 제목은 `title`, 내용은 `intro`. 문항 본문은 검색하지 않음
- **구현:** 기간은 설문 `startAt` 기준. 최근 N개월은 검색 시점부터 N개월 전 0시까지. 말일이 없는 달은 그달 마지막 날로 맞춤
- **구현:** 직접 기간은 시작일 0시부터 종료일 23:59:59.999까지
- **구현:** 초기화는 전체, 전체기간, 제목+내용, 검색어 비움, 1페이지
- **구현:** 상태 탭, 상태 드롭다운, 검색, 초기화는 그 시점의 브라우저 시각으로 상태를 다시 계산한다. 페이지 번호만 바꾸거나 화면을 그대로 두면 자동으로 다시 계산하지 않는다
- **구현:** 설문명은 말줄임. `title` 속성에 전체 제목. 클릭과 키보드는 상세로 이동
- **구현:** 진행예정 응답수는 `-`. 그 외는 `responseCount`
- **구현:** 진행중·종료만 응답보기 링크. 그 외는 비활성 버튼
- **미연결:** 삭제 확인 후 데이터는 삭제하지 않음

필수응답은 문항 속성으로 저장·표시합니다. 응답자가 비우지 못하게 막는 화면은 **미구현**입니다. 값이 없으면 필수응답으로 봅니다.

## 5. 대상 선택

등록·진행예정 수정의 모달입니다. 진행중 수정에서는 버튼이 비활성입니다.

### 모드

- 전체 회원: 지역·회원 구분을 비움
- 조건별 대상: 지역, 회원 구분

안내 문구: “지역 또는 회원 구분을 여러 개 고르면 그중 하나에 해당하면 포함됩니다. 지역과 회원 구분을 함께 고르면 두 조건을 모두 만족해야 합니다.”

같은 그룹은 `·`로 잇고, 지역과 회원 구분은 ` / `로 잇습니다. 예: `지역: 경기·충북 / 회원 구분: 농가`. 입력칸에는 그룹당 3개까지 보이고 나머지는 `외 N`입니다. 풍선 도움말과 상세 표시는 전체 이름입니다.

### 화면 검수용 옵션

코드 주석에 확정 업무 데이터가 아니라고 되어 있습니다.

- 지역: 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남
- 회원 구분: 농가, 법인, 유통, 기타

실제 코드값은 **확인 필요**입니다. 회원 포함 여부를 계산하는 서버 로직은 **미구현**입니다.

## 6. 미리보기

등록, 수정, 상세, 문항 편집에서 열 수 있습니다.

보여주는 값: 설문명, 소개, 기간, 참여 대상, 문항 제목·설명·유형·필수 표시, 선택지 또는 주관식 입력칸. 비어 있으면 `(설문명 미입력)`, `(설문 소개 미입력)`, `(문항 제목 미입력)`, `(선택지 미입력)`, `기간 미설정`, `참여 대상 미설정`처럼 표시합니다.

입력 요소는 비활성입니다. 응답은 저장되지 않습니다. Esc와 닫기는 미리보기만 닫고, 직전 버튼으로 포커스를 되돌립니다.

### UI

제목, 상태, 전체 유효 응답 수(`responseCount`), 테스트 데이터 미리보기, 기간, 검색, Excel 다운로드, 문항 목록, 결과 패널.

Mock 설문에는 문항별 `questionResults`가 없습니다. 그래서 기본 화면은 선택지 수치 없이 “문항별 응답 데이터가 연결되지 않았습니다.”와 유효 응답 수 `—`를 표시합니다. 상단 전체 응답 수는 설문 단위 값 그대로입니다.

### 통계 규칙

문항별 데이터가 연결되었을 때의 계산입니다. 현재 Mock에는 그 데이터가 없습니다.

- 응답 수·선택 수는 0 이상 정수. 불리언, 빈 값, 음수, 소수는 오류
- 선택 수 배열 길이는 선택지 수와 같아야 함
- 한 선택 수가 유효 응답 수보다 크면 오류
- 유효 응답 0인데 선택 수가 있으면 오류
- 단일 선택은 선택 수 합이 유효 응답 수와 같아야 함
- 복수 선택은 합이 유효 응답 수보다 커도 됨. 비율을 100%로 다시 나누지 않음
- 비율 = 선택 수 / 문항 유효 응답 수 × 100, 소수 한 자리
- 막대 너비는 그 비율 문자열. 100%로 자르지 않음
- 오류 문구: “응답 통계가 올바르지 않아 결과를 표시할 수 없습니다.”
- 주관식은 제출일시 최신순, 10건씩 페이지. 칸은 줄바꿈을 유지
- 주관식 표시 필드는 내용과 제출일시뿐

### 기간·Excel

기간 값을 검사한 뒤 목록은 거르지 않고 안내만 띄웁니다. “서버가 연결되지 않아 선택한 기간의 응답 결과를 조회할 수 없습니다.”

직접 기간이 비면 목록과 같이 “시작일과 종료일을 모두 선택해 주세요.”입니다. 형식 오류와 시작·종료 역전 문구도 목록과 같습니다. 검색 기준은 응답 제출일시이며, 검증 뒤에는 통계를 바꾸지 않고 서버 미연결 안내만 띄웁니다.

Excel: “서버가 연결되지 않아 Excel 파일을 다운로드할 수 없습니다.” 코드 주석은 문항 집계만 담고 주관식 원문과 응답자 개인정보는 제외한다고 되어 있습니다. 파일은 만들지 않습니다.

### 테스트 데이터 미리보기

개발·검수 전용입니다. 기본은 꺼짐. 설문 id가 문자열 `"25"`일 때만 켤 수 있습니다. 다른 설문은 체크가 비활성이고 “이 설문은 테스트 데이터 미리보기를 지원하지 않습니다.”

켜면 “테스트 데이터입니다. 실제 설문 응답이 아닙니다.”를 보이고, 문항 라벨은 “테스트 유효 응답 수”입니다. 상단 “전체 유효 응답 수”는 Mock의 설문 단위 값입니다. 테스트 값은 설문 객체나 `localStorage`에 쓰지 않습니다. 문항을 바꾸거나 미리보기를 켜고 끌 때 주관식 페이지는 1페이지로 돌아갑니다. 기간 검색과 Excel은 테스트 값을 내려받지 않습니다.

id 25, 선택지 3개인 현재 예시 문항 기준 테스트 값: 단일 14/10/6, 복수 24/18/12, 주관식 30건. 선택지 수가 3개가 아니면 코드의 다른 분배 규칙을 씁니다. 이 숫자는 운영 응답이 아닙니다.

| 대상 OR·AND | 화면 안내와 라벨 규칙만 구현. 같은 그룹 OR, 지역과 회원 구분 AND | 회원 판정 **미구현**. 코드값 **확인 필요** |

| 필수응답 | 속성 표시. 기본 켜짐 | 응답 강제 **미구현** |
| 응답 자격·중복 응답 | 관리자 코드에 없음 | **미구현**, 정책 **확인 필요** |
| 응답 제출 마감 | 관리자 상태는 종료일시에 종료로 바뀜 | 응답 제출 화면 **미구현** |
| 객관식 통계 | 위 통계 규칙. 데이터 없으면 `—`와 미연결 안내 | 실제 집계 **미연결** |
| 주관식 목록 | 최신순, 10건, 줄바꿈 유지 | 실제 답변 **미연결** |
| 응답 기간 검색 | 날짜 검증 후 미연결 안내. 화면 숫자는 유지 | 제출일시 조회 **미연결** |
| Excel | 클릭 시 미연결 안내. 주석은 집계만, 주관식 원문·개인정보 제외 | 파일 생성 **미구현** |

## 14. 코드와 기획 가정 사이 메모

아래는 구현이 서로 다르거나, 기획자가 같은 정책으로 볼 수 있으나 코드가 나뉜 부분입니다.

1. 목록 기간은 설문 시작일시, 응답 결과 기간은 응답 제출일시입니다. 오류 문구는 같고, 조회 기준은 다릅니다. 응답 결과는 기간으로 통계를 바꾸지 않습니다.
2. 목록·상세·수정 화면을 열어 두면 상태가 자동으로 다시 그려지지 않습니다. 목록은 탭·검색·초기화 때, 수정 완료와 종료 확인은 실행 때 다시 계산합니다.
3. 등록 Mock은 `targetLabel` 문자열만 있고, 작성 화면 초안은 `target` 객체입니다. Mock은 바꾸지 않았습니다. `target`이 원본, `targetLabel`은 표시용입니다.
4. 응답 자격, 중복 응답, 제출 마감 강제는 이 관리자 코드에 없습니다. 구현 완료가 아닙니다.
